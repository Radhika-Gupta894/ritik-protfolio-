## 🚀 How to Run Locally

Since this portfolio is **100% self-contained in `index.html`**, no build tools or package managers are required!

### Option 1: Direct File Opening
Double-click `index.html` to open it in any web browser (Google Chrome, Microsoft Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Optional)
If you prefer running via a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
Then navigate to `http://localhost:8000`.
